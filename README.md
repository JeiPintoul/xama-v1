# Xama

Responsive communication platform for communities, voice, and screen sharing.

## Requirements

- Node.js 22 LTS (22.13.0 or newer; use the latest patched release)
- Corepack

## Development

```bash
corepack enable
pnpm install
pnpm dev
```

Repository checks are available through `pnpm lint`, `pnpm typecheck`, `pnpm test`, and
`pnpm build`.
